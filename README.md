# EA_TOOLS — ชุดติดตั้ง

Add-in สำหรับ Revit 2024 / 2025 / 2026 / 2027

ที่นี่เก็บเฉพาะ **ไฟล์ติดตั้ง** — ตัวโค้ดอยู่ในที่เก็บส่วนตัวแยกต่างหาก

## ติดตั้งครั้งแรก

1. ไปที่ [Releases](../../releases/latest) โหลด `EA_TOOLS_x.x.zip`
2. แตกไฟล์ แล้ว **ปิด Revit ให้หมด**
3. รัน `EA_TOOLS_Setup.exe` → ติ๊กเวอร์ชัน Revit ที่ต้องการ → ติดตั้ง
4. เปิด Revit จะเห็นแท็บ **EA_TOOLS**

ถ้า Windows เตือน "Windows protected your PC" ให้กด **More info → Run anyway**
(เพราะไฟล์ยังไม่ได้เซ็นใบรับรอง) ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ

## อัปเดตครั้งต่อไป

กดปุ่ม **Update** ในแท็บ EA_TOOLS เมนู **File** — add-in จะมาดูเวอร์ชันล่าสุดที่นี่เอง
แล้วโหลดมาติดตั้งให้ ส่วนใหญ่ไม่ต้องปิด Revit

ถ้ารอบไหนมีการเพิ่มหรือย้ายปุ่ม จะบอกให้ปิด Revit แล้วรัน `EA_TOOLS_Setup.exe` อีกครั้ง
